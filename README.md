# Tsera

**Fully local voice dictation for Windows.** No data leaves your machine, no
account, no subscription, no connection required.

> *წერა* — "to write" in Georgian.

The good AI dictation tools live on macOS: Superwhisper, Wispr Flow, VoiceInk,
MacWhisper. On Windows there is almost nothing. Tsera fills that gap, and along
the way does something no one else does: **Georgian dictation**.

**Hold `Ctrl + Space` → speak → release**: the text is pasted at your cursor, in
any app. While dictating, a "TS" HUD with sound waves appears at the bottom of
the screen (then pulsing dots during transcription). Fully local and offline
(Parakeet-tdt-0.6b-v3 via sherpa-onnx, CPU).

**Hands-free mode (toggle): `Ctrl + Shift + Space`** — one press starts
dictation, a second one stops it. No need to hold anything: you can let go of
the keys and speak in between. Safety net: a forgotten toggle stops itself at
`max_duration_s`.

The space key is swallowed while Ctrl is held down, so no stray spaces are typed
into the active app during dictation.

## Interface

An **embedded web window** (pywebview / WebView2) with a "studio hardware"
identity (charcoal + signal amber + VU red, Anton / Inter / Roboto Mono). It
gives you: **live status** with a **waveform** that reacts to the current state
(idle / listening / transcribing), a **history** of your dictations (with copy),
**editable settings** (hotkeys, microphone, sounds, HUD, sensitivity, vocabulary
strength) and **vocabulary and corrections editors**. Closing the window
**minimises it to the system tray** (the app keeps listening); the tray icon
offers *Open* / *Quit*.

The front-end lives in `web/` (`index.html` + `style.css` + `app.js`), driven by
the Python engine through the `webui.py` bridge. Fonts are embedded as data URIs
in `web/fonts.css` (generated by `build_fonts_css.py` — this avoids the CORS
block on woff2 files under `file://`).

## Running

```
.venv\Scripts\python.exe app.py          # window + console (debug logs)
.venv\Scripts\pythonw.exe app.py         # window, no console
.venv\Scripts\pythonw.exe app.py --tray  # start minimised to the tray (login)
```

## Configuration (`config.json`)

`config.json` and `vocab.txt` are **local** (gitignored — they are your data):
they are created on first launch from `config.example.json` and
`vocab.example.txt`. A missing, incomplete or corrupted file never blocks
startup: the defaults below apply, and an unreadable `config.json` is set aside
as `config.json.broken`.

| Key | Default | Description |
| --- | --- | --- |
| `hotkey` | `ctrl+space` | Push-to-talk: a `modifiers+key` combo (the final key is swallowed while dictating) or a single key (e.g. `right ctrl`) |
| `toggle_hotkey` | `ctrl+shift+space` | Hands-free mode: first press starts, second stops. `null` or `""` to disable. May share the trigger key of `hotkey` |
| `model_dir` | `sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8` | Multilingual model directory |
| `model_dir_ka` | `sherpa-onnx-stt_ka_…` | Georgian model directory (optional) |
| `dictation_lang` | `multi` | `multi` (Parakeet, 25 languages) or `ka` (Georgian) |
| `num_threads` | `4` | CPU threads used for inference |
| `sample_rate` | `16000` | Sample rate expected by the models |
| `min_duration_s` | `0.3` | Below this, it was an accidental press — ignored |
| `max_duration_s` | `120` | Safety cut-off |
| `min_peak` | `0.008` | Minimum audio peak — below this it is silence and nothing is pasted (prevents beam search from hallucinating on background noise) |
| `sounds` | `true` | Feedback beeps (start / error) |
| `restore_clipboard` | `true` | Restore the clipboard after pasting |
| `overlay` | `true` | "TS" HUD + sound waves at the bottom of the screen while dictating |
| `device` | `null` | Microphone index, `null` = system default. The settings list shows **one entry per physical microphone** (see below). If opening fails — device held by another app, for instance — Tsera falls back automatically, and warns you if it had to switch to different hardware |
| `device_name` | `null` | Written automatically alongside `device`: a microphone's stable identity is its **name**, since PortAudio indices shift as soon as a device is plugged or unplugged |
| `vocab_file` | `vocab.txt` | Custom vocabulary (one word or phrase per line, `#` = comment) |
| `vocab_score` | `2.0` | Biasing strength (tested: 2 = gentle, 4 = strong, 8 = the word shows up everywhere) |
| `corrections` | `{...}` | Post-transcription replacements, case-insensitive, whole words (final casing + known mishearings) |
| `lang` | `en` | Interface language (`en` / `fr`) |

## Microphone selection

Windows exposes the **same** microphone through several audio host APIs (MME,
DirectSound, WASAPI, WDM-KS). Listing them raw is misleading twice over: three
physical microphones can produce fifteen entries, and a good number of those
entries cannot work at all. Tsera captures at 16 kHz, which WASAPI refuses in
shared mode — it only accepts the device's native rate — while WDM-KS demands
exclusive access and fails whenever another app is holding the microphone.

So the settings list shows **one entry per physical microphone**, under its
fullest name. Each entry keeps the ordered list of host APIs behind it, which
means a failure falls back to *the same microphone through another host* before
ever considering different hardware. You are only warned when the hardware
actually changes.

Availability is checked cheaply when the list is built, but that check only
validates formats — it cannot tell that a device is currently held by another
app. The stream is therefore opened for real when connecting, and that is what
decides.

## Custom vocabulary

Two complementary layers:

1. **`vocab.txt`** — listed words are boosted in the decoder (sherpa-onnx
   hotwords; this automatically switches to `modified_beam_search`, ~1.2× slower
   than greedy). Tested: "Superbase → Supabase", "Live Kit → LiveKit".
   An empty or missing file means greedy decoding (the original behaviour).
2. **`corrections`** (config.json) — deterministic post-processing: casing
   (`supabase` → `Supabase`) and recurring mishearings (`live kit` → `LiveKit`).
   When a name keeps coming out wrong in practice, add the observed error here.

Technical note: the exported model does not ship its sentencepiece model; a
`bpe_from_tokens.vocab` (uniform scores) is generated on first launch in the
model directory to encode the hotwords — biasing verified to work with it.

## Installing as a Windows app (shortcut + auto-start)

```
powershell -ExecutionPolicy Bypass -File install.ps1
```

This creates a **desktop shortcut** (`Tsera`, "TS" icon, opens the window)
**and** a shortcut in `shell:startup` so the app **starts automatically at every
Windows login** (with `--tray`: starts minimised, without opening the window).
Both launch through `pythonw.exe` (no console). Options:

- `install.ps1 -NoStartup` — desktop only, no auto-start
- `install.ps1 -Uninstall` — removes both shortcuts

Only one instance can run at a time (named Windows mutex), so auto-start plus a
double-click on the shortcut never create two keyboard hooks. The icon can be
regenerated with `python make_icon.py`.

Right-click the tray icon → **Quit**.

## Setup from scratch

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
curl.exe -L --ssl-no-revoke -o parakeet-v3-int8.tar.bz2 https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8.tar.bz2
tar -xjf parakeet-v3-int8.tar.bz2
```

(`--ssl-no-revoke` is needed with Avast, whose MITM certificate carries no
revocation information.)

Windows' bundled `tar` cannot decompress bzip2 ("unable to run program
`bzip2 -d`"), so use:
`python -c "import tarfile; t=tarfile.open('parakeet-v3-int8.tar.bz2','r:bz2'); t.extractall('.')"`.

## Dictation language

Two models, selected under **Settings → Dictation language**; switching reloads
the model (a few seconds). Parakeet remains the default.

| | Parakeet-tdt-0.6b-v3 (default) | Georgian |
| --- | --- | --- |
| Coverage | 25 European languages | ქართული only |
| Size | 641 MB (int8) | 477 MB (fp32) |
| Load time | ~12 s | ~16 s |
| Custom vocabulary | yes | no (see below) |

The Georgian model is **[`nvidia/stt_ka_fastconformer_hybrid_large_pc`](https://huggingface.co/nvidia/stt_ka_fastconformer_hybrid_large_pc)**
(NVIDIA, **CC-BY-4.0**, ~115 M parameters, trained on ~163 h of Common Voice 17 +
Fleurs), in the ONNX export by
[LukeJacob2023](https://huggingface.co/LukeJacob2023/sherpa-onnx-stt_ka_fastconformer_hybrid_large_pc).
Same family as Parakeet (NeMo transducer), so it loads through the same path.

Reported WER: **5.73%** on the Common Voice test set, **13.44%** on Fleurs. The
latter is the more representative of real dictation — noticeably worse than
French, on only 163 hours of training data.

**Custom vocabulary does not apply** in Georgian: it is written in the Latin
alphabet, for which this model has no tokens. Biasing would have nothing to
attach to, so it is disabled in this mode.

Installation (the directory lives outside the repository, like the other
models):

```
mkdir sherpa-onnx-stt_ka_fastconformer_hybrid_large_pc
cd sherpa-onnx-stt_ka_fastconformer_hybrid_large_pc
curl.exe -L --ssl-no-revoke -O https://huggingface.co/LukeJacob2023/sherpa-onnx-stt_ka_fastconformer_hybrid_large_pc/resolve/main/encoder.onnx
curl.exe -L --ssl-no-revoke -O https://huggingface.co/LukeJacob2023/sherpa-onnx-stt_ka_fastconformer_hybrid_large_pc/resolve/main/decoder.onnx
curl.exe -L --ssl-no-revoke -O https://huggingface.co/LukeJacob2023/sherpa-onnx-stt_ka_fastconformer_hybrid_large_pc/resolve/main/joiner.onnx
curl.exe -L --ssl-no-revoke -O https://huggingface.co/LukeJacob2023/sherpa-onnx-stt_ka_fastconformer_hybrid_large_pc/resolve/main/tokens.txt
```

Without this directory, the option stays greyed out in the settings.
